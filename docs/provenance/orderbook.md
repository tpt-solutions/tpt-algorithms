# Provenance: tpt-algo-orderbook

- Implementation: original code written for this repository.
- Algorithm sources: published papers only (Cont, Stoikov, Talreja 2010;
  Gould et al. 2013); dataset format from LOBSTER documentation (Huang and
  Polak 2011). See `docs/clean-room-notes/orderbook.md`.
- Third-party code: none. Dependencies: libm, thiserror, optional serde
  (all MIT OR Apache-2.0).
- Test data: seeded synthetic order flow (`tpt-algo-synth-data`, dev only).
  LOBSTER data not included; terms of use to be checked before publishing
  workflow docs.
- Status: clean-room claims are unverified by a second person.
